    Практика 1: FastAPI с Pydantic

    Описание

    Первая практика посвящена изучению основ FastAPI и созданию простого REST API с использованием Pydantic для валидации данных. Мы создадим API для управления "воинами" с различными характеристиками.

    Цели

    • Изучить основы FastAPI
    • Познакомиться с Pydantic моделями
    • Реализовать CRUD операции
    • Понять валидацию данных

    Архитектура

    Приложение использует простую архитектуру с временным хранилищем данных в памяти:

    practice_1/
├── main.py          # Основное приложение FastAPI
└── models.py        # Pydantic модели данных

    Модели данных

    RaceType (Enum)

    Определяет типы персонажей: - director - директор - worker - работник
    - junior - младший сотрудник

    Profession

    Модель профессии: - id - уникальный идентификатор - title - название профессии - description - описание профессии

    Skill

    Модель навыка: - id - уникальный идентификатор - name - название навыка - description - описание навыка

    Warrior

    Основная модель персонажа: - id - уникальный идентификатор - race - тип персонажа (RaceType) - name - имя персонажа - level - уровень персонажа - profession - профессия (Profession) - skills - список навыков (опционально)

    Код приложения

    models.py

    from enum import Enum
from typing import Optional, List
from pydantic import BaseModel

class RaceType(Enum):
    director = "director"
    worker = "worker"
    junior = "junior"

class Profession(BaseModel):
    id: int
    title: str
    description: str

class Skill(BaseModel):
    id: int
    name: str
    description: str

class Warrior(BaseModel):
    id: int
    race: RaceType
    name: str
    level: int
    profession: Profession
    skills: Optional[List[Skill]] = []

    main.py

    from fastapi import FastAPI
from typing import List, TypedDict
from pydantic import BaseModel
from models import Warrior, Profession
from typing_extensions import TypedDict

app = FastAPI()

# Временная база данных
temp_bd: List[dict] = [
    {
        "id": 1,
        "race": "director",
        "name": "Мартынов Дмитрий",
        "level": 12,
        "profession": {
            "id": 1,
            "title": "Влиятельный человек",
            "description": "Эксперт по всем вопросам"
        },
        "skills": [
            {
                "id": 1,
                "name": "Купле-продажа компрессоров",
                "description": ""
            },
            {
                "id": 2,
                "name": "Оценка имущества",
                "description": ""
            }
        ]
    }
]

@app.get("/")
def hello():
    return "Hello, [username]!"

@app.get("/warriors_list")
def warriors_list() -> List[Warrior]:
    return temp_bd

@app.get("/warrior/{warrior_id}")
def warriors_get(warrior_id: int) -> List[Warrior]:
    return [warrior for warrior in temp_bd if warrior.get("id") == warrior_id]

@app.post("/warrior")
def warriors_create(warrior: Warrior) -> TypedDict('Response', {"status": int, "data": Warrior}):
    warrior_to_append = warrior.model_dump()
    temp_bd.append(warrior_to_append)
    return {"status": 200, "data": warrior}

@app.delete("/warrior/delete{warrior_id}")
def warrior_delete(warrior_id: int):
    for i, warrior in enumerate(temp_bd):
        if warrior.get("id") == warrior_id:
            temp_bd.pop(i)
            break
    return {"status": 201, "message": "deleted"}

@app.put("/warrior{warrior_id}")
def warrior_update(warrior_id: int, warrior: Warrior) -> List[Warrior]:
    for war in temp_bd:
        if war.get("id") == warrior_id:
            warrior_to_append = warrior.model_dump()
            temp_bd.remove(war)
            temp_bd.append(warrior_to_append)
    return temp_bd

    API Endpoints

    GET /

    Простой endpoint для проверки работы сервера.

    Ответ: "Hello, [username]!"

    GET /warriors_list

    Получение списка всех воинов.

    Ответ: Список объектов Warrior

    GET /warrior/{warrior_id}

    Получение воина по ID.

    Параметры: - warrior_id (int) - ID воина

    Ответ: Список объектов Warrior (обычно один элемент)

    POST /warrior

    Создание нового воина.

    Тело запроса: Объект Warrior

    Ответ: 

    {
    "status": 200,
    "data": { /* объект воина */ }
}

    DELETE /warrior/delete{warrior_id}

    Удаление воина по ID.

    Параметры: - warrior_id (int) - ID воина

    Ответ: 

    {
    "status": 201,
    "message": "deleted"
}

    PUT /warrior{warrior_id}

    Обновление воина по ID.

    Параметры: - warrior_id (int) - ID воина

    Тело запроса: Объект Warrior

    Ответ: Список всех воинов

    Валидация данных

    Pydantic автоматически валидирует входящие данные:

    • Типы данных: Проверяется соответствие типов
    • Enum значения: Проверяется, что race соответствует RaceType
    • Обязательные поля: Проверяется наличие всех обязательных полей
    • Вложенные объекты: Валидируются profession и skills

    Пример ошибки валидации

    {
  "detail": [
    {
      "loc": ["body", "race"],
      "msg": "value is not a valid enumeration member; permitted: 'director', 'worker', 'junior'",
      "type": "type_error.enum; enum_values=[Enum('RaceType', {'director': 'director', 'worker': 'worker', 'junior': 'junior'})]"
    }
  ]
}

    • Swagger UI: http://localhost:8000/docs
    • ReDoc: http://localhost:8000/redoc

    Ключевые особенности

    FastAPI

    • Автоматическая документация - генерируется на основе кода
    • Валидация данных - встроенная поддержка Pydantic
    • Типизация - полная поддержка типов Python
    • Производительность - один из самых быстрых фреймворков

    Pydantic

    • Валидация - автоматическая проверка данных
    • Сериализация - преобразование в JSON
    • Типизация - строгая типизация моделей
    • Интеграция - отличная интеграция с FastAPI

    Улучшения

    Для улучшения кода можно:

    1. Добавить обработку ошибок - проверка существования воина
    2. Улучшить валидацию - добавить ограничения на уровни
    3. Добавить логирование - для отслеживания операций
    4. Реализовать пагинацию - для больших списков
    5. Добавить фильтрацию - по расе, уровню и т.д.
