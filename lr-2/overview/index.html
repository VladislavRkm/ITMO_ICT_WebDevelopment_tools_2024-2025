    Лабораторная работа 2: Асинхронное программирование

    Обзор

    Лабораторная работа 2 посвящена изучению различных подходов к асинхронному программированию в Python. Мы рассмотрим три основных способа выполнения параллельных задач: асинхронное программирование (asyncio), многопоточность (threading) и многопроцессность (multiprocessing).

    Цели работы

    • Изучить различные подходы к асинхронному программированию
    • Понять различия между threading, multiprocessing и asyncio
    • Научиться выбирать подходящий подход для конкретных задач
    • Освоить практическое применение асинхронности

    Структура работы

    Парсинг веб-страниц

    Цель: Реализация парсера веб-страниц с использованием разных подходов

    Что изучается: - Асинхронный парсинг с asyncio и aiohttp - Многопоточный парсинг с threading - Многопроцессный парсинг с multiprocessing - Сравнение производительности подходов

    Результат: Три версии парсера с разными подходами

    Подсчет суммы

    Цель: Реализация алгоритма подсчета суммы с параллельной обработкой

    Что изучается: - Разделение задачи на части - Параллельная обработка данных - Синхронизация результатов - Оптимизация производительности

    Результат: Эффективный алгоритм параллельного подсчета

    Технологический стек

    • asyncio - асинхронное программирование
    • aiohttp - асинхронные HTTP запросы
    • threading - многопоточность

    • concurrent.futures - высокоуровневый интерфейс
    • BeautifulSoup - парсинг HTML

    Ключевые концепции

    Асинхронное программирование (asyncio)

    Принципы: - Неблокирующие операции - Кооперативная многозадачность - Event loop - Coroutines и async/await

    Преимущества: - Эффективное использование ресурсов - Простота отладки - Отсутствие race conditions - Легкость масштабирования

    Недостатки: - Не подходит для CPU-интенсивных задач - Требует специальных библиотек - Сложность для новичков

    Многопоточность (threading)

    Принципы: - Параллельное выполнение потоков - Общая память - GIL (Global Interpreter Lock) - Синхронизация через locks

    Преимущества: - Простота использования - Хорошо подходит для I/O операций - Совместимость с существующим кодом

    Недостатки: - Ограничения GIL - Сложность отладки - Возможность race conditions

    Многопроцессность (multiprocessing)

    Принципы: - Параллельные процессы - Раздельная память - IPC (Inter-Process Communication) - Отсутствие GIL

    Преимущества: - Истинный параллелизм - Изоляция процессов - Подходит для CPU-интенсивных задач

    Недостатки: - Высокие накладные расходы - Сложность обмена данными - Большее потребление памяти

    Сравнение подходов

    Критерий asyncio threading multiprocessing
    Тип параллелизма Кооперативный Параллельный (с GIL) Истинно параллельный
    Память Общая Общая Раздельная
    Сложность Средняя Низкая Высокая
    Производительность I/O Отличная Хорошая Средняя
    Производительность CPU Плохая Плохая Отличная
    Масштабируемость Высокая Ограниченная Средняя
    Отладка Легкая Сложная Сложная

    Выбор подходящего подхода

    Когда использовать asyncio

    • I/O-интенсивные задачи - сетевые запросы, работа с файлами
    • Веб-приложения - FastAPI, aiohttp
    • Микросервисы - обработка множества запросов
    • Парсинг данных - сбор информации с веб-сайтов

    Когда использовать threading

    • Простой параллелизм - когда нужна простота
    • I/O операции - работа с файлами, сетью
    • GUI приложения - обновление интерфейса
    • Совместимость - интеграция с существующим кодом

    Когда использовать multiprocessing

    • CPU-интенсивные задачи - математические вычисления
    • Обработка больших данных - анализ, машинное обучение
    • Изоляция процессов - безопасность, стабильность
    • Максимальная производительность - когда важна скорость

    Практические примеры

    Асинхронный HTTP клиент

    import asyncio
import aiohttp

async def fetch_url(session, url):
    async with session.get(url) as response:
        return await response.text()

async def main():
    urls = ['http://example.com', 'http://google.com', 'http://github.com']

    async with aiohttp.ClientSession() as session:
        tasks = [fetch_url(session, url) for url in urls]
        results = await asyncio.gather(*tasks)
        return results

# Запуск
results = asyncio.run(main())

    Многопоточный парсер

    import threading
import requests
from concurrent.futures import ThreadPoolExecutor

def fetch_url(url):
    response = requests.get(url)
    return response.text

def main():
    urls = ['http://example.com', 'http://google.com', 'http://github.com']

    with ThreadPoolExecutor(max_workers=3) as executor:
        results = list(executor.map(fetch_url, urls))
        return results

# Запуск
results = main()

    Многопроцессный обработчик

    import multiprocessing
from concurrent.futures import ProcessPoolExecutor

def process_data(data):
    # CPU-интенсивная обработка
    return sum(x * x for x in data)

def main():
    data_chunks = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

    with ProcessPoolExecutor(max_workers=3) as executor:
        results = list(executor.map(process_data, data_chunks))
        return results

# Запуск
if __name__ == '__main__':
    results = main()

    Измерение производительности

    Метрики для сравнения

    1. Время выполнения - общее время работы
    2. Использование CPU - загрузка процессора
    3. Использование памяти - потребление RAM
    4. Пропускная способность - количество обработанных задач в секунду
    5. Масштабируемость - как растет производительность с увеличением нагрузки

    Инструменты измерения

    import time
import psutil
import asyncio
from concurrent.futures import ThreadPoolExecutor, ProcessPoolExecutor

def measure_performance(func, *args):
    """Измерение производительности функции"""
    start_time = time.time()
    start_memory = psutil.Process().memory_info().rss

    result = func(*args)

    end_time = time.time()
    end_memory = psutil.Process().memory_info().rss

    return {
        'execution_time': end_time - start_time,
        'memory_usage': end_memory - start_memory,
        'result': result
    }

    Обработка ошибок

    Асинхронная обработка ошибок

    import asyncio
import aiohttp

async def fetch_with_retry(session, url, max_retries=3):
    for attempt in range(max_retries):
        try:
            async with session.get(url) as response:
                return await response.text()
        except Exception as e:
            if attempt == max_retries - 1:
                raise e
            await asyncio.sleep(2 ** attempt)  # Экспоненциальная задержка

async def main():
    urls = ['http://example.com', 'http://invalid-url.com']

    async with aiohttp.ClientSession() as session:
        tasks = []
        for url in urls:
            task = asyncio.create_task(fetch_with_retry(session, url))
            tasks.append(task)

        results = await asyncio.gather(*tasks, return_exceptions=True)
        return results

    Многопоточная обработка ошибок

    from concurrent.futures import ThreadPoolExecutor, as_completed
import requests

def fetch_with_retry(url, max_retries=3):
    for attempt in range(max_retries):
        try:
            response = requests.get(url, timeout=10)
            response.raise_for_status()
            return response.text
        except Exception as e:
            if attempt == max_retries - 1:
                return f"Error fetching {url}: {e}"
            time.sleep(2 ** attempt)

def main():
    urls = ['http://example.com', 'http://invalid-url.com']

    with ThreadPoolExecutor(max_workers=3) as executor:
        future_to_url = {executor.submit(fetch_with_retry, url): url for url in urls}

        results = []
        for future in as_completed(future_to_url):
            url = future_to_url[future]
            try:
                result = future.result()
                results.append(result)
            except Exception as e:
                results.append(f"Error processing {url}: {e}")

        return results

    Синхронизация и координация

    Асинхронные примитивы

    import asyncio

async def worker(name, semaphore):
    async with semaphore:
        print(f"{name} starting work")
        await asyncio.sleep(2)
        print(f"{name} finished work")

async def main():
    # Ограничение количества одновременных задач
    semaphore = asyncio.Semaphore(3)

    tasks = [
        worker(f"Worker-{i}", semaphore) 
        for i in range(10)
    ]

    await asyncio.gather(*tasks)

    Многопоточная синхронизация

    import threading
from concurrent.futures import ThreadPoolExecutor

def worker(name, lock):
    with lock:
        print(f"{name} acquired lock")
        time.sleep(1)
        print(f"{name} released lock")

def main():
    lock = threading.Lock()

    with ThreadPoolExecutor(max_workers=5) as executor:
        futures = [
            executor.submit(worker, f"Thread-{i}", lock)
            for i in range(10)
        ]

        for future in futures:
            future.result()

    Лучшие практики

    Общие принципы

    1. Выбирайте правильный инструмент - подходите к задаче осознанно
    2. Измеряйте производительность - не предполагайте, а тестируйте
    3. Обрабатывайте ошибки - планируйте сценарии неудач
    4. Ограничивайте ресурсы - используйте пулы и семафоры
    5. Тестируйте на реальных данных - учитывайте специфику задачи

    Для asyncio

    1. Используйте async/await - избегайте блокирующих операций
    2. Группируйте задачи - используйте asyncio.gather()
    3. Обрабатывайте исключения - используйте return_exceptions=True
    4. Ограничивайте конкурентность - используйте семафоры

    Для threading

    1. Используйте пулы потоков - не создавайте потоки вручную
    2. Избегайте глобальных переменных - используйте локальное состояние
    3. Синхронизируйте доступ - используйте locks и queues
    4. Обрабатывайте исключения - ловите ошибки в потоках

    Для multiprocessing

    1. Минимизируйте передачу данных - используйте shared memory
    2. Используйте пулы процессов - управляйте жизненным циклом
    3. Обрабатывайте сигналы - корректно завершайте процессы
    4. Мониторьте ресурсы - следите за памятью и CPU

    Улучшения и расширения

    Возможные улучшения

    1. Комбинирование подходов - asyncio + multiprocessing
    2. Динамическое масштабирование - адаптивное количество воркеров
    3. Мониторинг производительности - метрики в реальном времени
    4. Распределенная обработка - использование нескольких машин
    5. Кэширование результатов - Redis или in-memory кэш
    6. Очереди задач - Celery или RQ
    7. Логирование и отладка - структурированные логи
    8. Тестирование - unit и integration тесты

    Интеграция с веб-фреймворками

    # FastAPI с асинхронными задачами
from fastapi import FastAPI, BackgroundTasks
import asyncio

app = FastAPI()

async def process_data_async(data):
    # Асинхронная обработка
    await asyncio.sleep(5)
    return {"processed": data}

@app.post("/process")
async def process_endpoint(data: dict, background_tasks: BackgroundTasks):
    background_tasks.add_task(process_data_async, data)
    return {"message": "Processing started"}

    Ключевые выводы:

    • asyncio - лучший выбор для I/O-интенсивных задач
    • threading - простой способ добавить параллелизм
    • multiprocessing - решение для CPU-интенсивных задач
    • Измерение производительности - критически важно для выбора подхода
    • Правильная обработка ошибок - залог стабильности приложения
